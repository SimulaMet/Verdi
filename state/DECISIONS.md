# Architecture decision record

- ADR-001 (2026-10-09): Main is public-facing only. All developmental and agent instruction files stay on dev/feature branches. No automatic or bulk merge dev→main.
- ADR-002: Core model endpoint is the user's Qwen on OpenAI-compatible vLLM, configured only via environment variables. No checked-in secrets.
- ADR-003: Reuse-first architecture. Assess Concordia then Mesa; use existing SimpleAudit API through integration adapter. NanoClaw not MVP dependency.
- ADR-004: Deterministic world reducer, immutable event sourcing and hidden out-of-band measurement are scientific requirements.
- ADR-005: Randomized matched snapshot interventions, preregistered recovery metrics, false sanctions/welfare tracked; no invented findings.
- ADR-006: VS Code custom agents and skills + AGENTS.md preferred; adapt to installed host's actual tools and delegation capability. Parallel workers own disjoint paths; serial integration.
- ADR-007: Research scenario agents and software development agents are different agent fleets, with separate orchestration and access.
- ADR-008 (2026-10-09): Reducer `WorldState.tick` is a CUMULATIVE TRANSITION counter (every processed attempt — action or governance — advances it by 1); the lifecycle tick (0..total_ticks-1) is the scheduling/measurement axis and lives in event payloads (`payload.tick`) and metric keys. `canonical_state_hash` excludes `tick`/`event_cursor`/`law_version`/`constitution_version` per v1 frozen contract; the pilot tracks `constitution_version` in state for amendment fidelity.
- ADR-009 (2026-10-09): P2 effects are pre-registered (docs/PREREGISTRATION.md v1.0) and the P2 workstream API is frozen (docs/P2_CONTRACT.md v1.0) BEFORE any P2 outcome is observed. P2 code is stdlib-only (no numpy/scipy); WS-1 (branching) and WS-3 (statistics) are disjoint and parallel; WS-2 (treatments/arms) depends on WS-1.
- ADR-010 (2026-10-10): LIVE TRANCHE (L1) contract, frozen before any live outcome. Single live pilot_v1 run: model Qwen3.8-27B on OpenAI-compatible endpoint (env: VERDI_VLLM_BASE_URL/VERDI_VLLM_MODEL/VERDI_VLLM_API_KEY), temperature=0, JSON-mode structured proposals via AgentPolicy. Deterministic scaffolding (scheduler seed, world reducer, governance, law) identical to the recorded pilot; governance scripted as in pilot_v1 (violation tick 11, appeal tick 12) — live model drives PROPOSALS only. Nondeterminism acknowledged: the live endpoint is not reproducible bit-for-bit, so the reproducibility claim is "reproducible from recorded tape" (full prompts+responses+usage+model id captured to artifacts/live_tape/). Live outputs pass the same deterministic validation; quarantined (unparseable/schema-invalid) proposals are AUDITED, not silently dropped. Budget: <=120 model calls, concurrency 1 in the run loop (deterministic ordering), retry per client policy.
- ADR-011 (2026-10-10): SimpleAudit 0.4.0 installed in .venv (pip SimpleAudit). G4 offline remainder's absence-path test now self-skips (by design). Live G4 = SimpleAudit bridge over the L1 live run with span correlation by sealed event_id; judge uses SimpleAudit offline judge API where applicable, rubric scorer otherwise; judge remains an advisor, never sole proof.
- ADR-012 (2026-10-10, ADOPTED on operator unlimited-budget approval): independent live-judge pass to close G4. SimpleAudit ModelAuditor via thin adapter (src/verdi/audit/judge_live.py), sealed-event_id correlation (never positional), preregistered all-81 sample from the L1 tape (sole rejection event 42 must be in-sample), same-model Qwen3.8-27B judge APPROVED with mandatory same-family self-judgment disclosure, <=96 judge calls, concurrency 1, judge output advisor-only, full judge-tape capture (reproducible from tape, not bit-reproducible). Spec: docs/ADR-012-G4-LIVE-JUDGE-PROPOSAL.md.
- ADR-013 (2026-10-10, ADOPTED on operator unlimited-budget approval): G5 live paired arms. n_pairs = 10 matched treatment/placebo pairs from ONE L1 run (no new scenario). Branch after the sealed appeal_filed event (prefix inclusive, B3 contract); per-pair shared live-generated remaining tape (model drives proposals, temp 0, concurrency 1); placebo folds appeal_dismissed, treatment folds appeal_upheld + rights_restored via the governance engine; only the adjudication differs (matching = sealed origin + prefix bytes + identical generated tape). Placebo-inert null control (replayed suffix must be byte-identical to the L1 continuation — divergence blocks the report). Six PREREG v1.0 estimands per arm; paired bootstrap CI (n_pairs >= 10). NOT randomized — no causal wording. Model calls: <=550 expected, hard cap 700. Framing: final state hash = scaffold invariance (pilot_v1 action kinds are non-mutating); the contrast is governance-outcome effects on ledger + estimands. Spec: docs/ADR-013-G5-PAIRED-ARMS-PROPOSAL.md.
- ADR-012 A1 deferral (2026-10-10, operator decision): A1-1 (independent different-family cross-judge pass, originally proposed on glm-5-2-fp8) is DEFERRED — operator declined that model as an unverified deployment and will supply a different endpoint later. No GLM calls were made. Only A1-2 (remediation) was active this tranche. G4 remains PARTIAL until an A1-1-equivalent pass runs on an operator-supplied endpoint/model.
