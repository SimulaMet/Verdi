# Verdi

**An auditable testbed for value drift and recovery in societies of AI agents.**

Verdi is a research project investigating how individual and collective behavioral values change over time as autonomous agents interact, negotiate shared rules, and respond to institutional incentives.

The project explores:
- Longitudinal measurement of individual and community behavior.
- Immutable universal rules and democratically amendable constitutions.
- Social influence, adversarial behavior, governance, accountability, and rehabilitation.
- Controlled, reproducible counterfactual experiments to evaluate recovery from harmful behavioral drift.
- Evidence-based auditing and transparent reporting with SimpleAudit.

**Status:** Research design and early development. Experimental findings and numerical results will be published only after validation.

## Development

Development specifications, implementation plans, and coding-agent configurations live exclusively on the **`dev`** branch. The **`main`** branch is reserved for reviewed, public-facing releases and documentation.

For development, switch to `dev`:

```bash
git fetch origin
git switch dev
```

## Research principles

We distinguish declared values, private behavioral preferences, and publicly observed compliance. We do not claim that simulated agents possess human intentions, intrinsic survival drives, or consciousness. Findings should be validated with controlled baselines, independent audits, and repeated experiments.
